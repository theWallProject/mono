How It Works

Three steps to accurate docs in your AI assistant.

1. Install a Package

Pick from hundreds of pre-built packages across npm, pip, and maven. Or build from any Git repo.

$ context install npm/react

2. Portable SQLite

Docs are indexed with FTS5 full-text search into a single portable .db file. Build once, share with your team.

$ ls .context/react@19.0.0.db

3. Query via MCP

Start the MCP server and your AI assistant — Claude, Cursor, VS Code Copilot — gets sub-10ms access to accurate docs.

$ context mcp
