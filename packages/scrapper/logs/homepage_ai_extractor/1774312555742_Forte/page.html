FAQ

I have a non-gaming project. Can I still use Forte’s products and solutions?

Yes. While Forte was started with the vision of creating a seamless, compliant platform with tools to help game developers integrate and manage web3 game economies, as we worked with developers we saw that the challenges the faced were fundamental challenges for any web3 projects that want to manage on-chain activity. The Forte Protocol solves not only the challenges game developers face, but it ultimately has value for any web3 project that needs to set rules for users and tokens.

What blockchains do you support?

The Forte Rules Engine supports Ethereum and Polygon, with Binance and other chain support coming soon.

What kinds of rules can the Rules Engine implement?

The Forte Rules Engine enables you to define the bounds of your token economy by limiting the minting, transfer, or burning of any given asset based on parameters like total value, account balance, or time period.
