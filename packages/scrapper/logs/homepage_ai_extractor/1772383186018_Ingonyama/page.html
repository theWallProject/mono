ICICLE, our flagship product, is a cutting-edge cryptography library designed to accelerate algorithms and protocols—starting with Zero-knowledge proofs—across diverse compute backends, including CPUs, GPUs, Apple Silicon, ZPU™ and more. Start Here.
IMP1
Built with ICICLE, this mobile-first proving framework delivers privacy-preserving zero-knowledge proofs directly to iOS and Android—up to 3× faster than RapidSnark. It’s lightweight, open-source, and optimized for fast, client-side performance with minimal setup required. IMP1 is built on ICICLE-SNARK, an end-to-end prover powered by ICICLE. Try It.
