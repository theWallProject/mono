World’s First Smart Container Innovation Lab

Selected Current Use Cases

Contopia Labs is a world-unique innovation research facility launched by Loginno for smart containers IOT to demonstrate the value that can be created through the smart containers involving data collection, analysis, and sharing of container data across the supply chain. This mechanism will benefit the entire intermodal logistics chain.

SOLAS VGM container weight measurement

Loginno has a granted patent for the scale-less measurement of the container’s weight. We have also won a grant from the Israeli Innovation Authority to trial scale-less weight measurement for containers.

Real-time container inventory management

We are producing a research-based tool for the management of container inventory using real-time information.

Smart Container <> Port connectivity

We are highlighting use cases for optimizing port operations based on smart container real-time data. Contopia partner for this use case is Navis.

CyberSeaSeal

We are working on the replacement of a container’s physical seal with a software certificate to allow frictionless borders and customs green lanes. Contopia partner for this use case is Lloyd’s Register.

Smart Container <> Vessel connectivity

We are examining three use case types by connecting the container through the vessel systems to the shore, the vessel’s AI and the crew. Contopia partner for this use case is Marlink.

GRF (Geospatial Route Forecast)

We are working on producing a geospatial forecast from standard documents.

Contopia Share

Loginno is also working on creating a crypto-powered revenue sharing model for smart containers.
