Q // A

What can be built using the Othentic Stack?

Absolutely anything, ranging from services and infrastructure to middleware and applications.
‍Read more

What programming languages does the Othentic Stack support?

Any. You can choose to implement the core logic of the network in any code language.

What is the current development stage of the Othentic Stack?

The Othentic Stack is fully operational, live on Ethereum Mainnet and supports EVM-compatible blockchains. It is constantly updated with more functionality added in each release.

Does the Othentic Stack run my network?

No. The Othentic Stack is entirely self-deploy architecture, configured according to your needs. The Othentic Stack includes node software for the network's Operators.

What does ‘shared security’ mean? What is an AVS?

Simply put, Proof-of-Stake (PoS) networks are secured by financial assets. Holders of these assets get rewarded for securing the network. Shared Security opens up additional opportunities for asset holders to secure more networks on top of the ones they already do, and not just blockchains. We refer to these networks as AVS - Actively Validated Services - a generalized name for any service or network secured by shared security protocols such as EigenLayer.

I am experiencing an issue when building with the Othentic Stack. How can I get help?

Common troubleshooting processes are detailed in our FAQ page. Feel free to reach out to the Othentic Labs team on Discord or Schedule a call.
