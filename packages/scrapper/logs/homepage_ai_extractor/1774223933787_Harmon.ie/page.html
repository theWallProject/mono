Need to Know More?

Does harmon.ie work with the New Outlook and Outlook Web App?

Yes — New harmon.ie is a web add-in that works with Outlook for Windows (new and classic), Outlook on the Web, and Outlook for Mac.

What’s the difference between harmon.ie Classic and New harmon.ie?

Both versions help you manage emails and documents in Microsoft 365 directly from Outlook. harmon.ie Classic supports Outlook Desktop and on-prem SharePoint, while New harmon.ie is designed for New Outlook, Outlook Web, Outlook for Mac and cloud-based Microsoft 365.

Where are my emails and documents stored?

All content saved with harmon.ie stays inside your organization’s Microsoft 365 environment — in SharePoint, Teams, or OneDrive. harmon.ie does not store or transmit your data externally.

How do I deploy harmon.ie to multiple users?

Administrators can centrally deploy harmon.ie using Microsoft 365 admin tools or Group Policy, depending on your Outlook version. Learn more in our deployment guides for New harmon.ie or for harmon.ie Classic.

Can I try harmon.ie for free?

Yes! You can try the full-featured harmon.ie products for harmon.ie for free for up to 21 days. No credit card required. For enterprise trials – guided trial for multiple users – contact us.

How does harmon.ie help with compliance?

By saving emails and attachments to Microsoft 365 with consistent metadata and retention policies, harmon.ie ensures full traceability and reduces legal and regulatory risk.

Does harmon.ie support SharePoint on-premises?

Yes — harmon.ie Classic (works inside classic Outlook for Windows) supports SharePoint on-premises as well as SharePoint Online.

Is support available for customers?

Absolutely. harmon.ie provides dedicated support, onboarding assistance, and admin documentation to help you deploy and manage successfully.
