The Solution

DYM provides the most advanced alcohol detection technology

The DYM sensor is a small finger pad, connected to the vehicle ignition system.
It performs real-time bio identification, alcohol detection and allows continuous monitoring.

The LED Array transmits each wavelength separately

The beam travels through the finger and the sensor reads the repeated beam

The algorithm converts collected data into a numeric blood alcohol level

The system identifies the driver by fingerprint and enables/prevents car ignition
