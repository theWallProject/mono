Our Technology

Tensera’s preload technology comprises a Preload Module which is integrated into the OS, enabling it to proactively and seamlessly load the app with its UIs into the device’s memory, and a Preload SDK which may be integrated into the app, enabling it to be preload aware.

The preload module is a Soong module implemented in Java, and the preload SDK provides an API which is aligned with the regular code flow of the app.
