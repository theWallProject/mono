Mission

First medical device with an
alert of an impending stroke
based on biological mimicry.

monitor

Avertto learns personalized hemodynamic features using unique long-term big data.

Detect

Avertto’s algorithm continuously analyzes stroke probability by detecting deviations from individual baseline activity.

alert

Avertto identifies a stroke risk, notifying and calls responsive care; enabling early intervention.
