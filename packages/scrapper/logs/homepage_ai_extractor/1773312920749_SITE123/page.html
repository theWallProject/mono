Häufig gestellte Fragen

Warum SITE123?

Weil es der einfachste und der schnellste kostenlose Website-Builder ist. Keine Notwendigkeit für Kodierungs- oder Designfähigkeiten. Nicht einmal Drag&Drop ist von Nöten. Laden Sie einfach Ihre Inhalte hoch und erhalten Sie eine funktionierende plattformübergreifende Website, die vollständig auf alle auf dem Markt verfügbaren Geräte abgestimmt ist.

Wie viel kostet es?

Es ist kostenlos! Unser Produkt wird kostenlos angeboten und beinhaltet Hosting und den Web-Editor mit all seinen Tools. Keine Zahlung, keine Testperiode, keine Verpflichtung. Wenn Sie eine benutzerdefinierte Domain verbinden möchten, werden Ihnen nur $ 10.8 pro Monat berechnet (im Voraus bezahlter Jahresplan). Worauf warten Sie also noch? Erstellen Sie jetzt eine Website.

Ist meine Website SEO-freundlich?

Eine Website, die von Suchmaschinen nicht indexiert werden kann, ist buchstäblich nutzlos. Daher stellen wir bei SITE123 sicher, dass Ihre Website für alle Suchmaschinen, einschließlich Google, vollständig sichtbar ist. Dies ist einer unserer wichtigsten Vorteile, und wir sind stolz darauf, Ihnen eine professionelle, qualitativ hochwertige Website anbieten zu können.

Wie kann ich meine Website online finden?

SITE123 stellt Ihnen eine benutzerdefinierte Sub-Domain kostenlos zur Verfügung. Ihre Domain-Adresse kann einfach auf dem Dashboard Ihrer Website gefunden werden.

Ich möchte einen benutzerdefinierten Domainnamen verbinden. Wie viel kostet mich das?

Mit dem kostenlosen Website-Builder SITE123 können Sie eine kostenlose Subdomain genießen, die automatisch von uns bereitgestellt wird. Mit SITE123 können Sie auch Ihre eigene Domain für nur $12,80 USD pro Monat verbinden, wenn Sie einen Jahresplan im Voraus kaufen, oder für nure 17 USD pro Monat, wenn Sie für einen Dreimonatsplan bezahlen. Leiten Sie Ihre Domain einfach an Ihre SITE123-Website weiter und genießen Sie es, sie im Web gezeigt zu werden.

Wie viele Websites kann ich unter meinem Konto registrieren?

Es gibt kein Limit - Sie können eine Website oder mehrere Websites unter einem Konto erstellen und alle mit einem einzigen Admin-Nutzernamen verwalten.

Wo wird meine Website gespeichert?

Die Frage ist heute wichtiger denn je, denn es wird vermutet, dass der Speicherort einer Website die Ladezeit direkt beeinflusst, was wiederum die Fähigkeit eines Unternehmens beeinflusst, Besucher auf die Website zu locken und zu binden. Um die Ladezeit zu verkürzen, werden SITE123-Websites auf weltweit verteilten Content Distribution Network (CDN)-Servern gespeichert. Ein Besucher lädt somit Ihre Seite am schnellsten, da sie vom nächstmöglichen Standort geladen wird. Erstellen Sie noch heute Ihre leistungsfähige Website.

Ich bin kein Designer. Muss ich einen Profi beauftragen, um meine Website erstellen zu lassen?

Der kostenlose Website-Builder von SITE123 ist so konzipiert, dass ihn wirklich jeder nutzen kann. Sie brauchen weder Designkenntnisse noch irgendeine Design-Software. Unser Website-Builder bietet eine Auswahl an fertigen Stilen und Layouts, mit denen Sie in nur wenigen Minuten eine absolut professionelle Website erstellen können. Alles, was Sie tun müssen, ist Ihre Inhalte hochzuladen und für jedes Tool aus der angebotenen Vielfalt die passende Vorlage auszuwählen. Alle Stile und Layouts lassen sich jederzeit ganz einfach austauschen.

Wie kann ich meine Website mit mobilen Geräten kompatibel machen?

Einfach wie eins-zwei-drei. Sie müssen sich keine Sorgen machen, weil wir das schon für Sie getan haben. Jede SITE123 Website wird automatisch auf Smartphones und Tablets angepasst. Erstellen Sie jetzt eine Website, damit Ihr Geschäft auf jedem Gerät perfekt aussieht.

Stellen Sie lizenzfreie Bilder zu Designzwecken zur Verfügung?

Absolut! Unser Web-Assistent enthält eine integrierte Bilddatenbank mit Hunderten von hochwertigen Bildern, die uneingeschränkt verwendet werden können und Ihnen helfen, Ihre eigene Website attraktiv zu gestalten.

Kann ich meine Website weiterhin selbst aktualisieren?

Sicher! Mit unserem Web-Assistenten können Sie Ihre Website nach der Veröffentlichung jederzeit und von überall auf der Welt verwalten und aktualisieren.
