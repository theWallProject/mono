Building on Talus

Talus is built on Sui using Move, a Rust-like programming language designed for blockchain. Talus uses both Move and Rust in its Agent Framework.

Sui's Parallel Execution allows independent transactions to process simultaneously. It also uses Programmable Transaction Blocks (PTBs), which can perform up to 1,024 unique operations in a single execution. By using an object-centric data model, Sui identifies which data each transaction touches upfront, ensuring that a spike in one app never slows down the rest of the network. Through this model, Sui can handle between 120k-300k TPS without issue.

By utilizing high-throughput architecture, Talus enables AI agents to execute complex, multi-step workflows with sub-second finality and predictable costs for both developers and users.
