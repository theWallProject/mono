Telco-Vision Framework

The glue of the network
  • One of our main advantages is the ability to “glue” any protocol or technology to another, therefore allowing network orchestration between different technologies such as 3G and 4G/5G, and different vendors.
  • As an example, we provided one of our clients a way to supports legacy IN (CS1) with their new IMS network while allowing their entire legacy IN bases services to remain functional and accessible even for IMS/VoLTE subscribers.
We have our own protocol stack
  • Another unique advantage of our solution is that Telco-Vision owns the complete protocol stack so you get a complete flexibility over all OSI layers above the transit (IP) including the SCTP/TCP.
  • This unique approach allows us to provide “Programable Protocol Gateway” so that our clients can create their own services in a simple HTTP Restful API and the Protocol Gateway converts it into the desire protocol (MAP/CAMEL/CS1+/Diameter Gy|Ro|s6a|Sls|Sh)

Telco-Vision 2026®

STP+

STP+ is in fact a two-in-one solution, it has a combined STP and Firewall functionality, while providing it with the best quality and performance to support more than 250,000 TPS per a single enterprise server with C-Link and without any session lost on any HW failure.

Our solution's STP is extremely flexible, using rules-based engine on any data attribute on any layer from SCCP till application layer MAP/CAP/etc, and also provide REGX abilities to match complex routing rules.

The SS7 firewall, which is a part of the STP product, also makes use of ML technology and can detect attackers in real-time, block them, and alert on the detected action.

DSC+

DSC+ act as DRA, DEA and Firewall all in a single solution, and holds multi protocols support with ability to add custom failures and AVP’s with just simple configuration. Diameter-Router is also holding security module that inspect each packet to ensure the safety of the internal network elements from DDoS or malicious messages. The solution includes support of Gy, Ro, Gx, Sy, Rf, Sh, SLg, SLh, S6a, S6c, S6d, S9, S13, Cx, Dx.

IWF+

IWF provides MAP-Diameter interworking function to allow 4G registration using MNO/MVNO HLR. Telco-Vision IWF was designed based on 3GPP TS.305 specifications, but adds several new functionalities to it. For example, the IWF allows data enrichments to the serving HLR for APN correction or overriding. The IWF supporting protocols are Gr, Gf, S6a, S6c, S6d, S13, S13a.

HSS+

HHS+ is HLR and HSS combined into a single solution. The solution supports various features that allow network optimization based on various vendors like Ericsson, Nokia, Mavenir and others, so that the different MSC, MMEs can use unique features that are missing in the standard 3GPP/ITU specs. For example, using OCSI for Ericsson CS1, or network preference in LTE under the MME settings, which provided by additional optional s6a AVP’s.

SMSC+

SMSC+ is a features rich Short Message Service Center with the below basic abilities:

  1. M3UA SIGTRAN
  2. Cloud native ready for AWS /GCP / Vmware
  3. SMPP 3.4 supported
  4. HTTP Restful and HTTP/XML support for web-based clients
  5. Real-Time Charging interfaces Gy/Radius/Custom HTTP API’s to any B/OCS external system
  6. Developed in C++ with async event loop architecture for best performance (no threads)
  7. ETSI MAP version 1,2,3 supported
  8. Ability to act as V-SSF for legacy OCS/SCP supporting CAMEL phase 1-4, CS1, CS1+, CS1R for rea-time billing
  9. SMPP TLS & HTTPS & HTTP over TLS
  10. ITU and ANSI support and protocols conversions
  11. CDR’s per any event
  12. Supporting 10,000 CAPS on single enterprise 1U server
