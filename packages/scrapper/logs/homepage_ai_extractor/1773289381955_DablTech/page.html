מערכת הכרויות DATELAND™

פרי פיתוח של החברה שלנו – פלטפורמת הכרויות דייטלאנד. למערכת זו שורה של פיצ’רים מתקדמים:

• הרשמה פשוטה עם פידבק בערזת AJAX
• כניסה מיידית דרך רשתות חברתיות
• usability מחושב עד כדי פרט אחרון
• GEO-targeting בכל העולם – קליטת משתמשים מכל העולם, לא רק בישראל
• צ’אט מתקדם שמנצל טכנולוגית comet server להתראות מיידיות
• אפשרות להעלאות ווידאו לפרופיל
• עיצוב אישי של הפרופילים
• בדיקה ידנית של כל התמונות והטקסטים וכתוצאה מזה מאגר משתמשים איכותי
Read more >>

• סקרים מסקרנים שמשלימים נתונים בפרופיל ומהווים גורם באלגוריתם של מציאת התאמות
• דירוג מהיר של תמונות “אהבתי” / “לא אהבתי” בסגנון טינדר
• מסנן הודעות נכנסות עוצמתי המופעל בקליק אחד
• אתר מותאים לניידים (הכולל צ’אט, תשלומים ועוד) הבנוי בעזרת jQuery mobile
• התראות מיידיות (“פוש”) למשתמשים במחשב ובסמארטפון בעזרת Chrome push notifications

כתוצאה אתרים רבים בחרו בפלטפורמת הכרויות שלנו, כמו למשל שת”פים עם פורטל חדשות נענע10, עם פורטל תפוז, אתר מכירים וכו.)
