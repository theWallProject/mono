Meet Vibe

Vibe is a totally new concept in lighting control, developed from the ground up using the latest computer and touch screen technology. It combines physical buttons and wheels for fast access with an extremely intuitive and flexible touch screen user interface users will be instantly familiar with because it is so similar to their smartphones and tablets.
