Baan Mail-Merge 7.1 released with additional new features that include using PDF graphic files (allows using a header, footer and background in PDF format) using borders for placing signatures in a certain location, line spacing and font scaling, and the possibility to add an additional page at the beginning, the end or in between pages in the PDF File produced from Baan/ERP Ln.
Another nice feature that was added is the possibility to run using the profile of different user – which was needed in order to run jobs without the need to give to all permissions to the – job – user.
For more release info, please refer to the Baan Mail-Merge 7.1 Release Notes
