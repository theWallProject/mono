Member's Group Chat

Built for members only. Only your members can view or participate in the group chat conversation. Best used in closed private group chat discussions.

  • ⚌ Only your members will be able to log in to the chat room
  • ⚌ Integrated with your own userbase
  • ⚌ Pre-integrated with WordPress plugin chat
  • ⚌ Easy integration - REST API, React, Angular, SDK, JS

Moderated Q&A Chat

Built for online events, Q&A chat, live stream, or webinars. A chat admin will need to approve every group message. Only approved chat messages will be visible to all.

  • ⚌ Q&A chat mode - easy to control what messages will be visible
  • ⚌ Only approved chat messages will be seen by all
  • ⚌ Only admins can approve chat room messages

Social Chat Room

Built for communities and open discussions. Engage your online audience with a real-time social chat. Add an open chat room to any webpage and connect with your audience. Social features can be turned on/off as needed.

  • ⚌ Send text, video & audio messages
  • ⚌ Send files such as PDF, Word, and Excel
  • ⚌ Share images and talk to anyone on the group chat and private chat

One-on-one Expert's Chat

Built for a private one-on-one conversation with an advisor. Only admins can start a chat and talk with users simultaneously. Great for consultants and job fairs, interviews, gurus and advisors.

  • ⚌ Only the advisor (admin) can initiate a conversation with others
  • ⚌ Users won't see other users nor start a conversations
  • ⚌ Chat face to face with a live video feature

Private Chats

Built for socializing in private conversations. Use private chats for private one-on-one chats. Chatters will be able to privately chat with everyone.

  • ⚌ One-on-one conversations with everyone in the chat room
  • ⚌ Only private chats, no group chat discussion
  • ⚌ Hold private audio and video calls, send private messages, and more

Get Paid Chat

Built for monetizing your chat (paid access PayWall). Perfect for charging your audience. Charge a fee for entering your chat or send a payment request.

  • ⚌ Set a paid access fee for your chat
  • ⚌ Direct payments between admin and a user
  • ⚌ Set a donation option
  • ⚌ Get paid for a limited time
  • ⚌ Get paid for a membership (subscription)
