Quality Management

Medical-grade Quality Management System

DUALTECH employs a variety of proven software engineering methods to ensure code quality:

  • Software architecture and design documentation by UML
  • Extensive use of version control systems (git, svn)
  • Code reviews for every commit
  • Unit-Tests for every module
  • Simulations and test harnesses
  • Static code analysis (Parasoft)
  • Issue and bug tracking (Jira)
  • Automatic documentation generation (Doxygen)

The quality objectives of DualTech group are:

  • Prevent and handle customer complaints
  • Compliance with agreed delivery times for the client
  • Maintaining project deliverables and products for years
