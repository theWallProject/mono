The revolutionary XVC-ULTRA Encoder sets a new industry standard in video quality, bit rate and ultra-low latency video delivery, providing the best-in-class HEVC/AVC UHD video quality at 4:2:2 10-bit.

XVC-ULTRA
KEY FEATURES

  • Broadcast level video quality
  • Supports HEVC (H.265) & AVC (H.264), main 4:2:2 10bit
  • Ultra-low Encoding latency < 10ms
  • End-to-End latency < 40ms
  • HDMI 2.0a 12G-SDI(*) input
  • RTP, RTSP/RTP, MP2TS, SRT, RTMP[S], HLS(*) streaming protocols
  • Web interface/REST API control
  • Low power consumption / small form factor
  • Scalable and future proof
  • (*) Future release
