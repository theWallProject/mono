How it works

Customers create a new account, make a transaction or use new payment methods

Network member sends a one-time fully anonymized query

The anonymized query is distributed to network members

A trust score is generated based on the consensus of the network

Data never leaves network members’ environment and, through Identiq’s patented protocol technology, remains completely private throughout the validation process.
