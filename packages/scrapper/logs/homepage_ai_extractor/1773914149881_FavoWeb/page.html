  • FRACAS Software for Monitoring of Operational Reliability

    FavoWeb is a Failure Reporting, Analysis, and Corrective Action System (FRACAS) software developed by ALD Software Ltd., a member of ALD Group. ALD Ltd. is a world leader in Reliability Engineering, Failure Analysis, Safety, and Quality Solutions. For more than 30 years, ALD has participated in hundreds of cutting-edge reliability and safety projects worldwide.
    FavoWeb FRACAS software provides unique and comprehensive solution for failure analysis, prediction, and prevention. The solution allows collecting thousands of faults, failures, and incidents of equipment, systems, and processes, analyzing data, determining the root causes, and offering corrective actions. FavoWeb FRACAS tool is cloud-based SaaS solution that is customizable, and algorithmically innovative.     Read More

  • Failure Analysis for Corrective / Preventive Action

    Corrective Action / Preventive Action (CAPA) is an extremely important stage of every FRACAS process. A purpose of Corrective Action / Preventive Action (CAPA) is to determine root causes of nonconformances and prevent their recurrence.
    FavoWeb FRACAS software has a built-in Corrective Action, Preventive Action process, CAPA process, 8D problem resolution processes.     Read More

  • Complete Web-Based FRACAS Software

    FavoWeb is a web-based Failure Reporting, Analysis, and Corrective Action System (FRACAS) tool. FavoWeb FRACAS is available as an on-premise installation or Cloud / SaaS (Software as a Service). All of the application features are web-based. All failure /incident data, failure analysis reports can be accessed from any site via the web. FavoWeb FRACAS software is installed on a main server and can be accessed via a web browser (CHROME, MS Explorer, FireFox, Safari etc.). Read More
