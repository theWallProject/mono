Log4j (CVE-2021-4428) vulnerability and Dream Report® software Ocean Data Systems Security Announcement

Log4j is a logging tool which is widely used in JAVA applications. Dream Report software does not use any JAVA code, and therefore does not contain or use that compromised Log4j tool in it.

As such, the recently found vulnerability (CVE-2021-4428) is not applicable to Dream Report software in any way, and doesn’t affect Dream Report software by any means.
