About Us

Since 2011, DerSecur has led innovation in application security with its flagship product, DerScanner, providing comprehensive analysis of both source and binary code. Supported by a team of 70 experts, DerSecur continuously enhances security technologies through focused research and development.

DerScanner’s SAST (Static Application Security Testing) uncovers vulnerabilities in both source and binary files, a critical feature for legacy systems or when source code access is restricted. Its DAST (Dynamic Application Security Testing) simulates external attacks, identifying flaws that only emerge during runtime, complementing SAST findings through interactive analysis.

DerScanner also includes Software Composition Analysis (SCA), which offers visibility into open-source components and dependencies, helping organizations mitigate vulnerabilities early and ensure compliance with licensing terms. Additionally, its Supply Chain Security feature monitors public repositories to assess the security posture of external packages.

Advanced techniques, including deobfuscation, decompilation, and Confi AI, enhance DerScanner’s accuracy, reducing false positives and negatives. With methods like lexical, syntactic, semantic, and control-flow graph analysis, DerScanner provides a robust evaluation of code security
