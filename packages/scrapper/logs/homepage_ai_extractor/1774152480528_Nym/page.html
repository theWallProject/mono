Nym’s Engine

Nym’s autonomous medical coding engine fits seamlessly into the existing coding workflow. It runs in the background, taking a first pass at coding patient encounters and routing successfully coded encounters to billing with zero human intervention.

Learn More About Nym’s Engine

CLU Technology

Enabled by innovative Clinical Language Understanding (CLU) technology and a rules-based approach to code assignment, Nym’s autonomous medical coding engine consistently maintains over 95 percent coding accuracy, produces fully transparent audit trails for every code assigned, and is automatically updated as soon as new coding guidelines are released.
