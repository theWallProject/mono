Construction quality control issues are likely to be missed; papers can easily be misplaced, and all of this can easily end up costing you a fortune. So why not stay in control and automate the QA/QC management process with revolutionary cloud-based software, saving time and money.

The Advantages of Using Vi-soft

Cloud-based software with web access:

  • Preloaded project tree with corresponding checklists.
  • No dependence on staff rotation.
  • Significant reduction in paperwork.
  • Unified docs generated according to preloaded forms.
  • Customizable and scheduled reports mailing.
  • Customizable management dashboard.

Special features:

Our software connects all parties involved in the project in contact into one collaborative, user-friendly environment – the project owner, contractors, architects, developers, labs, and surveyors.

You can coordinate an unlimited number of users, each with strictly defined access and editing rights. The main project can be divided into sub-projects, with dedicated project trees, to which you can attach the relevant QA/QC procedures for each branch.

Vi-soft has multilingual interface and all documents can be issued in a multitude of different languages.

After the project is finished, all  documents can be downloaded at once. This ensures that nothing is lost or goes unsigned.

We deliver the solutions you need:

We understand that depending on the project, the needs of the Quality managers vary. Because of this, we have built our system with different modules – these modules can be adjusted to match the projects requirements.

Docs storage has an easy-to-use search engine with convenient sort & filter possibilities, so you can retrieve any required document in a moment

All actions are transparent so you can keep track of any employee or sub-contractors’ progress. In addition, you can also get a full report on their activities at any given time.

Quality control

The basis of the system is a preapproved quality control plan with corresponding checklists. Tracking through dashboards and reports provides a company-wide view of different issues which may arise on the building site, helping you to make better informed decisions. The drill-down feature helps you to spot the problem promptly at a root level. This enables you to take decisive action immediately, long before the situation calls for a costly rework.

LEARN MORE

BIM Support

Vi-Soft allows uploading of Autodesk files for both 2D & 3D models. These drawings can be accessed and viewed by all project members. They can also connect critical quality control documents to specific model elements to exactly pinpoint quality issues to everyone and create mark ups in the models to indicate progress, problems and project – specific issues. There is no need for Autocad license purchase or installation of the complex tool to access this functionality in Vi-Soft

Construction projects are very complicated processes, demanding close, constant control and quick responses to different issues. Vi-Soft keeps you in control of any number of projects over sites in any given location – no matter how remote from your current location! With Vi-Soft, you can easily get the information that you and your colleagues need to stay on top of each and any project.
