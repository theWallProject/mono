Our Open Source Contributions 💗

Take a look at the projects we either proudly sponsor or have created:

Qwik

Qwik is a next generation web framework that can stream your JS apps to users resulting in instant loading and ultra-fast performance, revolutionizing how we build modern web applications. Our own Shai Reznik is currently leading the core team and community management for Qwik.

Qwik UI

Qwik UI is a project we started back in 2022 and is the world's fastest loading UI library, combining both Headless & styled copy-paste components automatically optimized for you. This project is the go-to component library for Qwik.

Vitest Browser Angular

vitest-browser-angular makes it possible to mount Angular components in the Vitest browser mode, preview them correctly and test them with ease. It provides routing utils and other helpers to make Angular component testing a breeze.

Observer Spy

Traditionally, testing complicated observables in Angular apps is super hard and require complex techniques such as "Marble Testing". The Observer-spy library was created to give an easy to use and simple alternative to marble tests and has become the recommended tool to use by members of both RxJS and NgRx teams.

Auto Spies

Auto Spies is an easy and type safe way to write spies and mocks for unit tests. It handles both sync but also async methods that return either promises or Observables. This library also has utility methods to create pre-configured fake observables and together with observer-spy completely removes the need for marble testing altogether.
