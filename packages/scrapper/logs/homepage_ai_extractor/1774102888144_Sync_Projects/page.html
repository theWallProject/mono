      מה אומרים עלינו

      סינק פרויקטים התאימו את התקן אלינו ולא אותנו אל התקן. המבדק עבר בהצלחה. המהנדס הבין את הצרכים שלנו, מיקד אותנו לשיפור תהליכים והוביל את התהליך בהצלחה.
      גם לאחר סיום העבודה נשמר הקשר ועד היום אנו פונים להיעזר ולשאול שאלות מקצועיות. תמיד מסבירים פנים.

      טל // אר.אס.טק

      שיתוף הפעולה עם סינק פרויקטים מצוין.
      חבר'ה נחמדים ונעימים. המקצועיות אצלם מעל הכל.

      ענבל // איתן ספקים

      סינק פרויקטים מאוד מקצועיים ואפקטיביים. הייתה הכנה טובה והתוצאה שעברנו את המבדק בהצלחה יתרה.
      העבודה עמם מקצועית ומסודרת. המלצתי ואמשיך להמליץ עליהם.

      יעל // אפריקס

      אנו עובדים עם סינק פרויקטים ומאוד מרוצים.
      כיום מלווים אותנו לתקן ISO 9001 ובהמשך נמשיך עמם לתקן HACCP.

      ליאונצ'ו // מטבח קיבוץ אור הנר

      עובדים עם סינק פרויקטים לתקן ISO 9001 ולרישום אמ"ר.
      ממליצים ולא רק לתחומים אלו...

      מיכאל // שפיר טכנולוגיות

      סינק פרויקטים סייעה לנו לקבל הסמכה לתקן ISO 9001, ליוותה אותנו לאורך כל התהליך ועזרה לנו בסידור התהליכים.
      התהליך הוכתר בהצלחה והמבדק עבר הרבה יותר קל ממה שציפיתי. אפשר רק להודות ולהגיד שהשירות נהדר!

      אנט // גלובוס מדיקל

      נעזרנו בסינק פרויקטים להטמעת 2 תקני ISO – תקן ISO 9001 ותקן ISO 27001. העבודה נעשתה בשיתוף פעולה מלא, התהליך עבר בקלות ובהצלחה.
      סינק פרויקטים מזמינים וזמינים והקשר עמם מוצלח, הכל באווירה נעימה ומקצועית. ירדו לפרטים ולא השאירו קצוות פתוחות.

      רינת // נאוגיימס

      סינק פרויקטים התאימו את התקן אלינו ולא אותנו אל התקן. המבדק עבר בהצלחה. המהנדס הבין את הצרכים שלנו, מיקד אותנו לשיפור תהליכים והוביל את התהליך בהצלחה.
