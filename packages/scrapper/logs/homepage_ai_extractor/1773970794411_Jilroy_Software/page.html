News & Events

02.02.2015
We are now offering our discovery tools as light weight utilities that can be called from a program as an API or as a command line. In this mode the full power of the our discovery and monitoring platform is not required.



  

Jilroy Software provides monitoring and inventory products and middle-ware software that focus on large scale and flexibility for Enterprises and Telecoms.

Genie, Jilroy's unique remote data collection, monitoring and discovery based inventory technology, enables remote collection of almost any parameter from any number of devices, at almost any protocol and scheme and at high frequencies. Our offering is designed both as a stand-alone products, and as a middle-ware software that enables applications and organizations to easily integrate the data discovered and collected in to their applications' logic.

Using Jilroy Software products and middle-ware software brings proactive monitoring a huge step closer to reality in large enterprises.
